隱私權政策

適用於「個人股票分析」桌面工具及本公開說明網站。生效與更新日期：2026-11-21。

存取的 Google 資料

程式在帳戶持有人授權後，以 Google Drive 唯讀權限（https://www.googleapis.com/auth/drive.readonly）讀取檔案名稱、識別碼、版本與修改時間，並將指定資料夾內的最新持股試算表匯出為 CSV。資料可能包含股票名稱、代號、股數、成本，以及表內其他欄位。

此 OAuth 權限範圍可讀取帳戶的 Drive 檔案，並非僅授權單一試算表；現有程式將用途限制於指定的持股資料處理流程。不要求 Gmail、通訊錄或交易帳戶權限。

使用目的與保存位置

資料僅用於本人持股分析、批次版本追蹤及結果核對。持股來源副本、計算結果與執行紀錄保存在本人管理的電腦資料夾；分析批次及交接文件可透過本人另行設定的 Google Drive 桌面同步功能保存至本人雲端硬碟。

OAuth 用戶端憑證、存取權杖及更新權杖保存在本人電腦的本機憑證檔案，不放入本公開網站、公開儲存庫或同步輸出資料夾。程式沒有另設對外提供的持股資料伺服器。

資料分享與 AI 處理

資料不出售，不用於廣告、信用評分或建立對外投資人資料庫。本人可另行指示 ChatGPT、Gemini 或 Claude 透過其服務與連接器讀取指定分析文件；手動啟動的 AI API 交接流程可將股票名稱與代號提供給 Google Gemini 查詢新聞，並將指定批次的持股與計算資料提供給 Anthropic Claude 核對。此類傳輸依本人選擇的操作與服務設定進行，不由本公開網站觸發。

使用者應在每次提供資料前確認傳輸內容及第三方服務的資料保留、使用與模型訓練設定；本政策不宣稱第三方服務一律不留存資料或不訓練模型。本人不授權將 Google 使用者資料用於訓練通用 AI／機器學習模型。Google 資料的使用及轉移應遵守 Google API Services User Data Policy，包括 Limited Use 要求。

保存期間、刪除與撤銷

現有工具不自動清除歷史批次，資料持續保留直到本人決定刪除。帳戶持有人可停止 Windows 排程，在 Google 帳戶的第三方連線設定撤銷授權，並刪除本機權杖檔案。撤銷後，需 Google 授權的後續讀取將無法繼續。

撤銷不會自動刪除先前匯出的資料。刪除資料時，還須分別處理本機批次、雲端同步副本、備份、回收桶及已交給 AI 服務的對話或檔案；第三方副本依該服務提供的刪除方式與政策處理。

本網站訪客

本網站只提供靜態文件，沒有 Google 登入、資料上傳表單、廣告或網站自行加入的分析追蹤碼。GitHub Pages 作為網站代管商可能處理 IP 位址及連線紀錄，詳見 GitHub 隱私權聲明。
